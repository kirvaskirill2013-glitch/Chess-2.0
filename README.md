# Chess 2.0 — Python + Kivy

Модульное шахматное приложение: игра с ботом или вдвоём, три уровня сложности,
шахматные часы, история ходов, отмена, сохранение позиции, статистика.

## Запуск на компьютере

```bash
python -m pip install -r requirements.txt
python main.py
```

## Сборка Android (Linux)

Установи Buildozer и Android build dependencies, затем в папке проекта:

```bash
buildozer android debug
```

Готовый APK появится в `bin/`.

## Важные замечания

- Для правил используется библиотека `python-chess`; она отвечает за легальные
  ходы, рокировку, взятие на проходе, превращение, шах, мат и ничью.
- Сложный бот использует alpha-beta поиск глубины 3. На слабых телефонах
  расчёт может занять некоторое время.
- Фигуры отображаются Unicode-символами. Если на устройстве отсутствуют
  шахматные глифы в системном шрифте, потребуется добавить шрифт с поддержкой
  шахматных символов в assets и подключить его к Label.
- Сохранение хранится в `saved_game.json`, статистика — в `statistics.json`.
